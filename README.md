# 1lv1.com

The 1lv1 brand site, served by GitHub Pages at https://1lv1.com.

- `index.html` is the whole site in one file: a React app with a Three.js 3D hero, bundled with its scripts and styles.
- `CNAME` sets the custom domain, and `.nojekyll` tells GitHub to serve the files exactly as they are.
- `og.png` is the link-preview image. `favicon.svg`, `404.html`, `robots.txt` and `sitemap.xml` are the other site files.

To change the site, edit the source and replace `index.html` with the new build.
